# JKS Exporter

🚀 Утилита на Go для мониторинга Java Keystore-файлов (.jks / .jceks), выводящая метрики для Prometheus.

## 🧩 Возможности

- Поддержка форматов `JKS` и `JCEKS`
- Счётчик оставшихся дней до истечения сертификатов
- Метки `status=valid/expired/unknown`, `expires=YYYY-MM-DD`
- Вывод в `.prom` файлы для `node_exporter` (textfile collector)
- Обработка нескольких `.env` конфигураций
- Поддержка CLI: `start`, `stop`, `status`, `restart`
- PID-файл, лог-файлы по каждому `.env`

---

## ⚙️ Структура каталогов

```text
/opt/jks-exporter/
├── config/
│   ├── any_keystore.env
│   └── another_keystore.env
├── logs/
│   ├── any_keystore.log
├── jks-exporter-linux
```

💡 Keystore-файлы и `.prom` файлы могут лежать **в другом месте** (например, на смонтированной шаре).

---

## 📄 Пример `.env` файла

```env
KEYSTORE_PATH=/mnt/shared/keystores/any_keystore.jceks
KEYSTORE_PASS=changeit
METRIC_NAME=cert_expiry_days
EXPORT_MODE=file
PROM_FILE_DIR=/mnt/node_exporter/
PROM_FILE_NAME=any_keystore.prom
SERVER_NAME=prod-node-01
PORT=:10000
```

---

## 🔄 Описание `EXPORT_MODE`

| Значение     | Описание                                      |
|--------------|-----------------------------------------------|
| `file`       | Вывод метрик в `.prom` файл                   |
| `web`        | HTTP-сервер с `/metrics`                      |
| `both`       | И файл, и HTTP-сервер                         |

## 📦 Сборка

```bash
GOOS=linux GOARCH=amd64 go build -o jks-exporter-linux jks-exporter.go
```

---

## 🚀 Запуск

```bash
./jks-exporter-linux start     # Запуск с PID-файлом
./jks-exporter-linux stop      # Остановка по PID
./jks-exporter-linux status    # Проверка статуса
./jks-exporter-linux restart   # Перезапуск
```

---

## 📈 Пример метрик

```text
# File generated by jks-exporter
# Content for PROMETHEUS
cert_expiry_days{name="alpha_key", keystore="/mnt/shared/keystores/any_keystore.jceks", status="valid", expires="2025-06-28"} 79
cert_expiry_days{name="beta_cert", keystore="/mnt/shared/keystores/any_keystore.jceks", status="expired", expires="2024-01-15"} -83
```

## 🐳 Пример Dockerfile

```Dockerfile
FROM openjdk:11-jre-slim

WORKDIR /app
COPY jks-exporter-linux /usr/local/bin/jks-exporter
COPY config/ ./config/
RUN chmod +x /usr/local/bin/jks-exporter

CMD ["/usr/local/bin/jks-exporter", "start"]
```

Пример запуска:
```bash
docker build -t jks-exporter .
docker run -d --restart=always \
  -v /mnt/shared/:/mnt/shared/ \
  -v /mnt/node_exporter/:/mnt/node_exporter/ \
  jks-exporter
```

---

## ⏰ Пример через `cron`

Создай файл `/etc/cron.daily/jks-exporter`:

```bash
#!/bin/bash
cd /opt/jks-exporter
./jks-exporter-linux start > /dev/null 2>&1
```

Сделай его исполняемым:
```bash
chmod +x /etc/cron.daily/jks-exporter
```

## 📎 Зависимости

- Go >= 1.18 (для сборки)
- Java keytool (из OpenJDK)
- node_exporter с `--collector.textfile.directory=...`
